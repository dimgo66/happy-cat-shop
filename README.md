# 🐱 Счастливый котик — интернет-магазин

Маленький, но полностью рабочий магазин музыкальных и художественных товаров.
Витрина — статичный сайт (HTML + CSS + JavaScript) **без сборки и без зависимостей**.
Редактирование товаров и цен — через страницу `admin.html`.

## 🎮 Как играть (ссылка для детей)

Сайт уже опубликован, ставить ничего не нужно:

| Что | Ссылка |
|---|---|
| 🛍 Магазин | **https://dimgo66.github.io/happy-cat-shop/** |
| 🛠 Кабинет владельца магазина | **https://dimgo66.github.io/happy-cat-shop/admin.html** |

**Что можно делать в магазине:**

1. Выбрать товар в каталоге, зайти в карточку и положить в корзину.
2. Поменять количество, выбрать доставку курьером или самовывоз.
3. Заполнить имя и телефон, нажать «Оформить заказ» — появится номер заказа
   вида `СК-250114-4821`. Если вернуться на страницу корзины позже, номер
   и состав заказа сохранятся.
4. Проверить, что доставка становится бесплатной при заказе от 5 000 ₽.

**Что можно делать в админке:**

* Поменять цену — число прямо в таблице.
* Поставить остаток `0` — товар станет «Нет в наличии».
* Нажать «✎» и переписать название, описание или характеристики.
* Нажать «+ Добавить товар» и придумать свой товар (даже «Летающий рояль»).
* Нажать «💾 Сохранить данные» — магазин сразу изменится.

Правки в интернете сохраняются **только в том браузере, где играли**: испортить
настоящий сайт или чужую игру невозможно. Кнопка «Сбросить локальные правки»
возвращает всё как было — это и есть «начать заново».

## Запуск на своём компьютере

```
node tools/serve.cjs
```

| Что | Адрес |
|---|---|
| Витрина | http://127.0.0.1:5173/index.html |
| Админка | http://127.0.0.1:5173/admin.html |

Витрина работает и без сервера — просто откройте `index.html` двойным кликом.
Админка без сервера тоже открывается, но сохраняет правки только в браузере
(см. раздел «Режимы сохранения»).

## Как добавить, изменить или убрать товар

**Способ 1 — админка (рекомендую).** Откройте `admin.html`:

* **Цена, остаток, категория, название** правятся прямо в таблице — щёлкните по ячейке.
* **Название, описание, характеристики, фото, скидка и плашка** — кнопка «✎» в строке товара.
* **Добавить товар** — кнопка сверху, заполните поля и нажмите «Применить».
* **Удалить товар** — кнопка «🗑». Если он лежит у кого-то в корзине, об этом будет предупреждение.
* **Убрать из продажи, не удаляя** — поставьте остаток `0`: товар останется на витрине
  с пометкой «Нет в наличии» и неактивной кнопкой.
* Внизу — кнопка **«💾 Сохранить данные»**.

**Способ 2 — вручную.** Всё лежит в одном файле `assets/js/catalog.js`:

```js
{
  id: 'g-05',                 // уникальный! он же имя файла картинки
  title: 'Гитара «Барсик» 1/2',
  category: 'guitars',        // id из CATEGORIES
  price: 5900,
  oldPrice: 6900,             // необязательно — зачёркнутая цена
  badge: 'Новинка',           // необязательно: «Хит» или «Новинка»
  rating: 4.5,
  reviews: 12,
  stock: 7,                   // 0 → «Нет в наличии»
  desc: 'Короткое описание для карточки.',
  specs: ['Размер: 1/2', 'Струны: нейлон'],
  image: 'assets/img/products/g-05.jpg'   // необязательно, своё фото
}
```

После ручной правки обновите страницу с Ctrl+F5. Проверить синтаксис:

```powershell
node --check assets/js/catalog.js
```

Товар сразу появляется в каталоге, в поиске и в подборке на главной — HTML править не нужно.
Порядок товаров в файле = порядок в каталоге по умолчанию.

### Контакты и доставка

Настройки магазина (название, телефон, почта, адрес, часы работы, стоимость доставки
и порог бесплатной доставки) — объект `SHOP` в том же `catalog.js`.
Они правятся в разделе «🏪 Настройки магазина» и сразу подставляются в контакты на витрине.

### Картинки товаров

* По умолчанию сайт ждёт `assets/img/products/<id>.svg`.
* Нужно своё фото — загрузите его в админке (PNG, JPEG, WebP, GIF или SVG до 2 МБ),
  поле `image` проставится само.
* Заглушка для новых товаров рисуется автоматически:

```powershell
node tools/generate-images.js
```

## Режимы сохранения

У админки их два, и она сама выбирает подходящий:

| Режим | Когда | Что происходит |
|---|---|---|
| **Сервер** | открыто через `node tools/serve.cjs` | «Сохранить данные» пишет прямо в `assets/js/catalog.js`. Перед записью создаётся резервная копия. |
| **Браузер** | сервер не запущен, или запущен с `--read-only` | Правки хранятся в браузере (localStorage), витрина сразу их показывает. Кнопка «⬇ Скачать catalog.js» отдаёт готовый файл для ручной замены. |

В шапке админки всегда видно текущий режим. В режиме браузера правки действуют
только в этом браузере — на телефон или другому человеку они не попадут.
Кнопка «Сбросить локальные правки» возвращает витрину к содержимому файла.

**Резервные копии.** Последние 20 копий лежат в `.backups/` и доступны в админке
с кнопкой «Восстановить». Наружу эта папка не отдаётся.

```

assets/js/app.js           логика витрины: корзина, каталог, заказ

assets/js/image-gen.js     генератор SVG-заглушек (браузер + Node)

assets/img/products/       23 SVG-иллюстрации товаров

tools/serve.cjs            сервер: статика + API сохранения
tools/generate-images.js   генерация заглушек для новых товаров
tools/smoke-test.cjs       47 проверок витрины (jsdom, без браузера)

tools/admin-browser-test.cjs 29 проверок админки в реальном браузере
tools/check-layout.cjs     проверка раскладки в Chrome/Edge
tools/measure.js           служебный скрипт для измерения раскладки
```

## Заказ и доставка

* Курьер — 390 ₽, бесплатно при заказе от 5 000 ₽. Самовывоз — всегда бесплатно.
* Проверяются имя, телефон, e-mail (если заполнен) и адрес (для самовывоза не обязателен).
* После оформления — номер вида `СК-250114-4821`, корзина очищается,
  состав заказа можно распечатать.

**Важно:** заказ никуда не отправляется — это витрина без бэкенда. Владельцу нужно
связаться с покупателем по указанному телефону. Если понадобится реальная доставка
заказов (Telegram, e-mail, CRM) — дописывается один обработчик `submit` в `assets/js/app.js`.

## Проверка

```powershell
npm install                    # один раз, для тестов (jsdom)

npm test                       # витрина: 47 проверок
npm run test:admin             # API сохранения, копии, валидация: 41 проверка
node tools/admin-browser-test.cjs   # админка в браузере (сервер поднимает сам)

node tools/serve.cjs 5173      # в одном окне
npm run test:layout -- http://127.0.0.1:5173   # раскладка в реальном Chrome
```

Тесты админки **не портят данные**: API-тест возвращает `catalog.js` в исходное
состояние в конце, а браузерный поднимает сервер в режиме `--read-only` и
дополнительно сверяет контрольную сумму файла до и после прогона.

## Публикация

Витрина статическая: скопируйте `index.html`, `catalog.html`, `product.html`,
`cart.html`, `assets/` в корень хостинга. Точка входа — `index.html`.

Для публикации файлы `admin.html` и `tools/` не нужны, и их лучше не выкладывать:
API сохранения работает только на локальном сервере. Если всё же публикуете админку,
заранее замените демонстрационные телефон, почту, адрес и цены на реальные.
